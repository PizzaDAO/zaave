# Zaave 🍕

Aave, but the yield is pizza. Stake stablecoins, keep your principal, and get a set number of pizzas every month.

Deposits go into Aave v3. Each month on **Za Day**, the interest becomes **slices** (8 slices = 1 pie) that you redeem for real pizza. You can withdraw your principal any time.
